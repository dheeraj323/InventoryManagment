IMPORTANT DEVELOPMENT RULES:

* Do not overwrite my existing files blindly.
* Do not migrate the entire project to a different framework.
* Do not replace Expo with bare React Native.
* Do not create duplicate screens or duplicate navigation systems.
* Do not change the Stitch visual design without explaining why.
* Do not add unnecessary UI components.
* Do not implement all features in one uncontrolled operation.
* Before modifying a file, inspect its current contents.
* Reuse existing components whenever possible.
* Make small, testable changes.
* Preserve working functionality.
* Never use fake success messages for unimplemented backend operations.
* Clearly label mock data and mock API behavior.
* Keep the code compatible with Expo CLI.
* Ask for clarification only when a decision is genuinely required; otherwise make a reasonable implementation decision and document it.
